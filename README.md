# Vider Enjoy

A Next.js application scaffold for an AI chat experience.

## Structure

- `app/` — app routes and UI
- `lib/` — engine and service integrations
- `supabase/` — database schema
- `tests/` — lightweight verification tests

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — run the app in development mode
- `npm run build` — create a production build
- `npm run start` — start the production server
- `npm run test` — run project tests
